# Muhammad Abdullah — CV

Digital Marketer & Web Developer — Gujrat, Pakistan.

Static multi-page CV site with profile, skills, projects, education (BISE Gujranwala result cards) and contact, plus a print-ready full CV page.

Live: **https://muhammad-abdullah-cv.vercel.app**

## Pages
- `index.html` — Overview
- `skills.html` — Skills
- `projects.html` — Projects (Umar Hayat Chaska Point, Gulnish Crochet, Euro Pizza Café)
- `education.html` — Academic record with result cards
- `contact.html` — Contact
- `print-cv.html` — Full single-page CV for print / PDF

## Tech
Plain HTML + CSS (self-hosted variable fonts), no build step.
